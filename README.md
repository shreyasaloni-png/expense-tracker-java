# Personal Expense Tracker (Java)

## Description
A simple Java console application to track daily expenses. Users can add, view, and calculate total expenses.

## Features
- Add expense (category + amount)
- View all expenses
- Calculate total spending
- Data saved using file handling

## Technologies
- Java
- ArrayList
- File Handling

## How to Run
1. Compile:
   javac Main.java Expense.java ExpenseManager.java

2. Run:
   java Main

## Files
- Main.java
- Expense.java
- ExpenseManager.java
